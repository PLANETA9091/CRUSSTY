# Next Measured Giant Goal

Date: 2026-05-20 CEST

This is the next honest scale target. It does not claim literal unlimited
scale. It takes the current stress-corpus mixed-gameplay artifact and pushes
the join path until the full tier actually comes online, then repeats the
same tier under warm, restart, recovery, and evidence-bundle checks.

## Goal

Get the current artifact to a green P250 stress-corpus mixed-gameplay gate
with full-online join coverage, then carry that same artifact through repeat,
warm, restart/recovery, forced-ticket, and evidence-bundle checks before
stepping to P500.
