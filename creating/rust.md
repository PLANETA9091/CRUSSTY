# <img class="page-icon" src="/CRUSSTY/assets/images/icons/rust.svg" alt="Rust"> Rust

Rust is the reference module path. The ABI (`cplug-abi`) plus the SDK
(`cplug-sdk`) give you hooks, class lookup, main-thread dispatch, logging
and ASM patching — all typed.

platform built yet.
